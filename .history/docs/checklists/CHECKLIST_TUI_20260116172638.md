# Checklist: TUI (optional)

## Removability
- [ ] TUI package deletable without touching core/cli
- [ ] Installed only via extras

## mikomn Integration
- [ ] Uses BaseTuiApp as app scaffold
- [ ] Theme cycling works via 't' key
- [ ] Command palette accessible via Ctrl+P
- [ ] Platform layout adapts to terminal size (expanded/compact/condensed)
- [ ] Uses mikomn panes (HeaderPane, SidebarPane, LogPane, etc.)
- [ ] Uses mikomn widgets (FileDirPicker, KeyHints, ConfirmModal)

## Message-driven
- [ ] Widgets/panes emit messages
- [ ] Screens handle messages
- [ ] App dispatches Specs to services

## No logic in UI
- [ ] No business logic in screens/panes/key handlers
- [ ] No direct IO/subprocess in widgets

## Scroll rules
- [ ] Screen does not scroll
- [ ] Panes declare scroll intent explicitly

## Tests
- [ ] Test message → dispatch behavior, not widget layout
